# 星序 / ORBIT

2026-10-28，用户确认应用名称从「慢慢 / Momo」更新为「星序 / ORBIT」。主题以星点、路径和精密参考线呼应品牌背景，保留原生桌面应用的简洁与亲切感。

## 视觉

- 七个节点连接成开放轨迹，末端为一枚小星光。轮廓有转折与圆形关节，表达有序推进和灵活连接。
- 专注区加入淡色轨道与参考刻线；侧栏、应用图标和小窗使用简化标记。全部为 Qt 矢量绘制，适配不同显示比例。
- 界面不直接使用公司全称、机械臂剪影或行业标语；品牌联系通过数量、结构与精密感表达。
- 保留圆角卡片、柔和背景和留白。琥珀色只用于关键入口与标记末端，阅读和日常状态以蓝灰为主。

## 界面语言

品牌副句为「让每一步，连成方向。」；今日标题为「把今天，连成方向。」。功能按钮继续使用清楚的动作名称，例如「新建任务」「新建聊天」「绑定已有聊天」，不以隐喻代替操作含义。

主题覆盖主界面、托盘、专注小窗、待处理窗口和原生步骤图。通用对话框继承统一样式。

## 维护与兼容

`theme.py` 集中保存品牌名称、色板及 Qt 样式；`art.py` 生成轨迹标记与图标。步骤图的原生画笔使用同一套配色。

可见名称与数据身份分开：`QApplication.applicationDisplayName` 使用新名称；`applicationName=Momo`、`organizationName=MomoLocal` 保留现有 Qt 数据位置。现有服务、锁、Git 分支前缀和配置键不因视觉更新而重命名。

验证使用独立临时数据和示例事项。预览图展示界面外观，不代表用户的实际任务或进度。
