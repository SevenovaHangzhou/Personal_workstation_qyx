# 星序 / ORBIT

2026-10-28，用户确认应用名称从「慢慢 / Momo」更新为「星序 / ORBIT」。主题以星点、路径和精密参考线呼应品牌背景，保留原生桌面应用的简洁与亲切感。

## 视觉

- 六边形的六个顶点各有一颗四芒小星，中心保留一颗较大的十字星，形成七星布局。2026-10-31 根据用户确认更新应用图标。
- 专注区加入淡色轨道与参考刻线；侧栏、应用图标和小窗使用简化标记。界面标记使用 Qt 矢量绘制，桌面图标使用同构 SVG，适配不同显示比例。
- 界面不直接使用公司全称、机械臂剪影或行业标语；品牌联系通过数量、结构与精密感表达。
- 保留圆角卡片、柔和背景和留白。琥珀色只用于关键入口与标记中心，阅读和日常状态以蓝灰为主。

## 界面语言

品牌副句为「让每一步，连成方向。」；今日标题为「把今天，连成方向。」。功能按钮继续使用清楚的动作名称，例如「新建任务」「新建聊天」「绑定已有聊天」，不以隐喻代替操作含义。

主题覆盖主界面、托盘、专注小窗、待处理窗口和原生步骤图。通用对话框继承统一样式。

## 维护与兼容

`theme.py` 集中保存品牌名称、色板及 Qt 样式；`art.py` 生成六边形十字星标记与图标，`assets/orbit.svg` 用于发布安装包。步骤图的原生画笔使用同一套配色。

可见名称为「星序 / ORBIT」。默认数据路径自 2026-11-07 改为 `Sevenova/Orbit`，启动时迁移旧目录并保留兼容链接；Qt 内部应用标识继续兼容已有桌面窗口关联。现有服务、锁、Git 分支前缀和配置键不随视觉品牌更改。
