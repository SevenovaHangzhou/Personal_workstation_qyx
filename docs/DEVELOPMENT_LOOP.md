## 30天留存确认流程

仅候选已完成日报文件及对应Git快照、已缓存压缩输出、已结束课程/答疑输出。每组完整检查文件、目录、修改时间和链接，近期变化则整组保留；最多200组，预览10分钟失效，确认令牌一次使用。每次用户确认后再次核对 inode、模式、大小及修改时间，暂存并再核对，通过系统 gio 移入回收站。失败尝试恢复原位置并报告，取消只停止尚未开始的组；不清空回收站。核心数据与实际 Git 仓库/分支不纳入候选。操作结果保存至日报账本，已清理的日报文件可从数据库读取正文。

留存测试覆盖范围筛选、活动任务排除、近期成员保护、链接隔离、一次性令牌、变化拒绝、失败恢复、用户取消不调用清理、确认才调用，以及核心记录保留。另在隔离 XDG_DATA_HOME 中用真实 gio 验证合成文件进入可恢复的回收站；未操作真实留存。最新完整回归230项通过，追加日报正文回退后7项存储测试通过。
