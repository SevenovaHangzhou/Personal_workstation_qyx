# 手动工作日志与周报

星序侧栏「日报与同步」下方提供两个入口：

- **下班**：总结今天 00:00 至点击时刻的工作日志。
- **总结周报**：总结本周一 00:00 至点击时刻的工作记录。

时间按 Asia/Shanghai 计算。仅收集工作软件中任务明确绑定的 Codex 聊天，以及人工进展记录；工作、Demo、日常任务均可出现在本地日志中。文本压缩复用系统当前 Codex CLI 配置，其余收集、时间筛选、去重、归档由代码完成。

结果只保存在当前数据空间的 `daily/work-logs/`，可查看历史和复制。手动日志不创建 issue、不发送 Linear 评论、不创建 Git 留存，也不修改 22:00 自动日报的周期和同步账本。

生成在后台进行，关闭日志窗口仍继续；可以取消或重试。重试保留原统计截止时间和已成功的摘要。应用完整退出后中断的任务等待手动重试，不自动重发模型请求。模型摘要不会自动改变任务状态。
