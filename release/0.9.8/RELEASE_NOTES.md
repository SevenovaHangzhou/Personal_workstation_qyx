# 星序 ORBIT 0.9.8

新增简单的显示设置，适应不同屏幕与阅读习惯。

- 偏好设置新增「显示」页：字体 12–18 px、窗口大小预设、最大化与自动适配；实时预览，保存后沿用，取消恢复原状。
- 自动模式记住手动调整的窗口位置与大小，屏幕变化后收回可见范围；保留系统高分屏缩放。
- 窄窗口使用紧凑专注条，任务详情可独立展开，看板按状态纵向排列；设置入口固定在侧栏底部。
- 课程在窄屏改用章节下拉选择，知识与答疑可独立展开；保留阅读、作答和问答输入。
- Linux 与 Windows 共用这些改进。

下载：Linux 选择 .deb 或 linux-x86_64.tar.gz；Windows 选择 setup.exe 或 windows-x86_64.zip。校验值见 SHA256SUMS / WINDOWS-SHA256SUMS。

应用关闭窗口后驻留托盘，完整退出再启动可使用新版。发布包不含用户数据或登录凭据。
