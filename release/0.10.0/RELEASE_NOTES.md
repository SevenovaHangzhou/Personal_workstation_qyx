# 星序 ORBIT · 知序 LUMA 0.10.0

拆分为两款独立的原生桌面应用，均提供 Linux 和 Windows 安装包。

- **星序 / ORBIT**：工作、Demo、日常任务，保留 Codex、Linear、日报和 Git 留存。
- **知序 / LUMA**：学习、专注、课程生成与阅读、核心知识和随课答疑。
- 首次启动先完整备份，再按分类迁入独立数据空间，保留 ID、关联与历史；支持迁移中断恢复。
- 星序侧栏新增「下班」「总结周报」，手动报告先本地查看；22 点同步仍按原流程运行，新日报只收集明确绑定工作版任务的聊天。
- 「My Issues」与「新建任务」并列，只导入本地尚未创建的 Linear issue，重复导入会再次检查，保留已有任务。
- 简化工作界面，改善窗口拖动、窄屏布局与按钮边框；补齐 Linux 桌面依赖检查。
- 源码分别在 `main`（星序）和 `luma`（知序）维护，两边均支持 Linux 与 Windows。

下载时按产品选择：`orbit` 为星序，`luma` 为知序。Linux 使用 `.deb` 或 `.tar.gz`；Windows 10/11 x64 使用 `setup.exe` 或 `.zip`。校验值与构建来源见对应 SHA256SUMS 和 manifest 文件。

升级前请从旧版托盘菜单完整退出。原始数据与迁移备份保留在本机，两款应用有独立桌面入口、设置、托盘和 OTA 身份。发布包不含用户数据或登录凭据；Windows 安装包未进行商业代码签名。
