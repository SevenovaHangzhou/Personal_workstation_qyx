# 星序 ORBIT 0.9.0

本机原生 Qt 任务与学习应用。支持工作、学习、Demo、日常分类，任务串并联规划、合入/移出与安全撤销，明确绑定 Codex 聊天，工作任务对应 Linear issue。

学习任务支持后台课程生成、整门课程绑定、断点续读、固定核心知识区与随课答疑。22:00 收集日报、创建待同步工作 issue、保存本地 Git 补丁；支持人工进度记录与确认后的 30 天留存清理。

本次发布整理文档和预览图，移除不受支持的 Python 3.10 二进制及重复截图。运行时仅保留所需 Starlette 并发适配依赖，移除未使用的 FastAPI 安装要求。修复打包后系统工具继承应用动态库路径的问题；现有 Codex 配置、认证继续复用。

提供自带 Python/Qt 的 Linux x86_64 便携包和 `.deb`。新增 `--version`、隔离 `--self-test`、固定依赖的构建配方、SHA-256 校验和第三方许可证。

数据目录保持兼容。升级前从旧版托盘退出。未自动提交代码、修改 Linear 状态或迁移真实任务库。Python 源码运行仍需 3.11+；本次安装包使用 Python 3.12.14，在 Ubuntu 22.04 构建。无图形环境的验证使用 Qt offscreen，不代表已验证所有桌面托盘实现。

验证：251 项源码回归通过；冻结应用、便携包和 Debian 包解包后的隔离自检通过，覆盖服务、任务结构撤销、进度记录、14 章课程阅读、教学 skill 与系统 Git。两个安装包的 SHA-256 已核对，未包含用户数据或凭据。
