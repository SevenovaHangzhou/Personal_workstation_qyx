# 星序 ORBIT 0.9.2

- 修复 Debian 命令符号链接及源码符号链接的启动目录解析。
- 增加 GitHub 正式版本 OTA：后台检查和下载，完整退出后切换，下次启动生效。
- 用户目录统一更新，无需 sudo，保留原安装和上一更新版本。
- SHA-256、大小、清单和平台校验，安全解包与隔离离线自检；启动失败时自动回退，重复打开不会误回退。
- 偏好设置、托盘菜单和版本号提供更新状态、手动检查、停止准备与取消待更新。

Linux x86_64，glibc 2.35+。0.9.0 需要手动升级到本版一次，随后支持 OTA。关闭主窗口会驻留托盘，需选择「退出」才切换更新。

不修改用户任务数据，不包含 API key 或登录凭据；Codex CLI 沿用本机配置。安装前请退出旧版。
