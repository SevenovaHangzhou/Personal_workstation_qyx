# 星序 ORBIT · 知序 LUMA · Evaluator 0.10.1

三款原生桌面应用均提供 Linux x86_64 和 Windows 10/11 x64 安装包。

- **星序 / ORBIT**：新增 LAN Mesh 同事发现与双向配对；指定聊天后整理项目知识库，预览确认再共享，双方各自保留本地副本，无需第三方服务器。
- 日报、下班日志和周报可通过只读共享供管理员收集。连接 Evaluator 时仅共享明确授权的工作 issue 日志与进度；完整日报、周报需另外授权，不自动混入 issue 统计或模型问答。
- **星序评估 / Evaluator**：新增独立管理员安装包，支持员工与设备归档、授权日志收集、证据问答和进度台账；完整日报、周报单独查看。
- **知序 / LUMA**：继续提供学习与专注独立应用，保持与工作数据隔离。

按文件名前缀选择产品：`orbit` 为工作版，`luma` 为学习版，`orbit-evaluator` 为管理员版。Linux 安装 `.deb` 或解压 `.tar.gz`；Windows 安装 `setup.exe` 或解压 `.zip`，无需另外安装 Python。

共享默认关闭，首次配对需核对双方配对码，管理员授权可撤销。发布包不包含用户数据或登录凭据；Windows 安装包未进行商业代码签名。

ORBIT 与 LUMA 可通过现有 OTA 获取本次更新，从托盘完整退出后下次启动生效。Evaluator 使用独立安装入口和 `Sevenova/OrbitEvaluator` 数据目录，当前手动更新。下载附件含 Linear、同事协作及管理员离线使用手册；各平台 manifest 和 SHA256SUMS 记录源码提交、文件大小与校验值。
