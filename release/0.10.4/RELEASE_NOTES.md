# 星序 ORBIT · 知序 LUMA · Evaluator 0.10.4

修复中文 Windows 启动时出现 `gbk codec can't decode byte` 的问题。

- 明确以 UTF-8 读取协作状态、迁移记录、应用标记、知识库和 OTA 清单，避免使用系统默认 GBK。
- Windows 应用和启动器在解释器启动前固定启用 UTF-8，不依赖用户设置环境变量或修改系统语言。
- 增加中文内容保存后重启、GBK 编码环境、中文及 emoji 安装和数据路径的检查，安装包与便携包均验证连续两次启动。
- 保留 LAN Mesh 协作、管理员授权日志收集，以及独立 Evaluator 和知序 LUMA 安装包。

**如果旧版已经无法启动，请直接下载安装 0.10.4，或解压新的便携包后运行。无需删除数据目录、修改系统区域设置或重新绑定账号。**

Linux x86_64：安装 `.deb` 或解压 `.tar.gz`。Windows 10/11 x64：运行 `setup.exe` 或解压 `.zip`；均无需另装 Python。

文件名前缀 `orbit` 为星序工作版，`luma` 为知序学习版，`orbit-evaluator` 为独立管理员版。后者采用独立安装目录和数据空间，当前手动更新。星序与知序保持 OTA 支持，从托盘完整退出后下次启动生效。

附件包含 Linear、同事协作和管理员离线手册、源码提交记录及 SHA-256 校验清单。安装包不包含用户数据或登录凭据；Windows 安装包未进行商业代码签名。
