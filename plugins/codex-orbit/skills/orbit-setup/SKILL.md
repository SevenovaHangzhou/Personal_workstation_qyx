description: 完成星序插件首次设置：配置本机连接并创建 Codex 每日日报自动化。用于安装后初始化、补建日报定时任务、修改连接与工作目录。
---

安装后的 MCP 初始化指令、首次设置和补建日报任务都执行 [每日自动化流程](references/daily-automation.md)，在 Codex 中自动创建可见任务并查重，无需用户另发设置口令。自动触发只完成日报流程后继续用户原任务，不打开连接卡片；不等待密钥输入才创建本地日报任务。仅修改密钥或工作目录时不重建自动化。

用户要求连接设置时，调用星序 ORBIT 的 `open_settings` 打开本机原生卡片。让用户在卡片中填写 Linear API Key、测试账号并保存；密钥不要发到聊天，也不作为工具参数、命令参数或代码内容。

卡片独立于 Codex 运行，打开后不要阻塞等待或循环查询。告知用户保存后可直接继续原任务，插件会立即读取新配置。用户要求继续时再用 `status` 核对，执行其原有请求。

若返回 `ui_unavailable`，根据原因说明需要本地可见桌面或当前 Python 中的 `requirements-ui.txt` 依赖。可使用返回的不含密钥的 `local_command` 从本机终端打开。CLI 用户也能用 `scripts/mcp.py --setup` 隐藏输入并验证密钥。不要改用聊天收集密钥。

已配置的用户可以随时重新打开卡片；更换或移除只影响插件自己的密钥，桌面版凭据保留。

用户要求修改自动日报时间或停用时，先用 `prepare_daily_automation` 查已绑定 ID，再使用 Codex 宿主自动化工具更新；用户选择系统调度的旧安装仍使用 `open_schedule`。补跑和查看结果使用 `open_schedule`。默认每天本机时间 00:00；只整理明确绑定任务的摘要和结果记录，不自动写入 Linear。
